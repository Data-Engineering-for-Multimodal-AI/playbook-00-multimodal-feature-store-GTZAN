# Data licenses

This file lists the datasets and models this playbook uses, where they come from, and their licenses. The code in this repository is MIT-licensed. That license does not cover third-party data or models; each one keeps its own license, listed below.

## Datasets

| Dataset | Source | License | In this repo |
|---|---|---|---|
| GTZAN genre collection, Kaggle version (1,000 30-second clips in `genres_original/` and a mel spectrogram image per clip in `images_original/`) | [Kaggle: andradaolteanu/gtzan-dataset-music-genre-classification](https://www.kaggle.com/datasets/andradaolteanu/gtzan-dataset-music-genre-classification) | Unclear (see Notes) | No. Downloaded by `make data` (`python download_data.py` in `mmfeaturestore/`) into `mmfeaturestore/sample_data/` (1.2 GB). Needs a Kaggle API token |
| Audio feature scaler (mean and standard deviation of the 28 audio features) | Measured over 999 GTZAN clips | Not stated (derived from GTZAN) | `mmfeaturestore/models/audio_scaler.json` (1.4 KB) |
| Synthetic clips (tones and noise in three made-up genres, with a spectrogram image each) | Generated by this repository's code | MIT (this repository) | No. Written at run time by `make run` and the `make try-*` targets into `mmfeaturestore/output/` |

## Models

| Model | Source | License | How it's used |
|---|---|---|---|
| ResNet-18, ImageNet weights (`ResNet18_Weights.IMAGENET1K_V1`) | [torchvision](https://pytorch.org/vision/stable/models.html) | Not stated in this repo. torchvision's code is BSD-3-Clause | Image encoder for the spectrogram or album-art image of each song. Downloaded by `make setup` (45 MB) |
| all-MiniLM-L6-v2 | [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) | Apache-2.0 | Text encoder for lyrics (`mmfeaturestore/src/encoders/text.py`). Downloaded from Hugging Face on first use |

## Notes

- GTZAN: the license is unclear. `download_data.py` says "The audio comes from commercial recordings; it is available for research and can't be redistributed, so each reader downloads it." The recordings are not in this repository.

## Citations

- GTZAN: G. Tzanetakis and P. Cook, "Musical genre classification of audio signals", *IEEE Transactions on Speech and Audio Processing* 10(5), 2002.
- ResNet: K. He, X. Zhang, S. Ren and J. Sun, "Deep Residual Learning for Image Recognition", arXiv:1512.03385, 2015.
- all-MiniLM-L6-v2: no citation given by the source.
